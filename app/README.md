# AI Memory Lab

桌面版包含真实模型实验、28轮结构化演示和临时模拟沙盒。全部体验均在 Windows 桌面应用内；离线演示不请求模型。

## 真实模型实验

启动后进入“开始实验”：保存并选择模型配置 → 使用内置守则或确认自定义守则 → 创建实验。“对话”用于发送消息、处理候选；“记忆演化”优先比较前后变化；“三维图谱”分析已登记关系。实验记录集中管理打开、重命名、重置、删除和导出。对话与获准记忆会发给所选供应商，模型连接测试也可能计费；使用前确认 Base URL 可信。

支持 OpenAI Chat Completions、Anthropic Messages、Gemini GenerateContent；第三方服务选择 OpenAI 兼容协议，自填模型 ID。Base URL 填 API 前缀，如 `https://api.openai.com/v1`，不包含 `/chat/completions`。HTTPS 为默认要求；自建本机服务可使用 `http://localhost:端口/v1`。不绕过 TLS 验证，不跟随重定向。兼容服务若不支持 SSE，可关闭“流式回复”。

Key 默认仅保留在 Rust 进程内；选中保存时交给Windows Credential Manager。模型配置只保存非敏感字段。编辑配置时 Key 留空保留原凭据；新建不需要 Key 的本机服务可留空。不要在聊天中粘贴凭据。

内置完整守则来自私有项目根目录 `memory-rules.md`，由 Rust 编译期嵌入，无网络也能读取；守则不随私人记忆或对话导出到公开网站。自定义 Markdown 导入或粘贴后先显示名称、全文预览及 SHA-256，经确认才用于新实验；导入失败保留已选版本。可还原草稿或恢复内置守则。“查看实验守则”展示当前实验的固定全文、来源与完整哈希；旧记录没有来源登记时显示未记录，不推定为内置版本。

首次无实验时显示可跳过的四步帮助：连接模型 → 选择守则 → 开始对话 → 查看结果。“使用帮助”可随时重开；帮助本身不请求模型。“离线示例”使用独立 SIMULATED 回放，不创建真实实验。只在浏览器偏好中保存帮助是否跳过，不保存实验内容。

真实模型实验持久化在系统应用本地数据目录 `local.memorylab.desktop/experiments.sqlite`。每个实验保存守则原文及 SHA-256，旧实验不随新守则改变；“重置为新实验”保留原实验并新建空状态。重新打开会显示尚未结束请求的实际输入，确认没有其他窗口处理后，通过“结束上次中断请求并恢复”继续；模型输出和记忆提交分别保存、分别展示。

模型只提出候选，内核核对原文、角色、权限、时效、冲突和删除限制。清晰的本人普通陈述可自动保存；本人允许留存的健康、住址、联系方式和家庭自述通过本地准入后直接写入，不弹保存确认。成功写入且读回角色 Markdown 后，状态栏提示本地位置和隐私风险。不能核实、引用或推断内容不因模型标签自动晋级；旧候选仍须核验，不补造来源。密码、密钥、证件及银行账号等始终禁存。当前本地提取器支持明确句式，不能代替完整自然语言理解；未提取项会如实显示无变化，不编造记忆。

SQLite 为事务权威源；每个实验在应用本地数据目录 `role-memory/<实验ID>/<可信角色标识>_mem.md` 保存可读投影，绝不写安装目录。文件以同卷临时文件、刷盘、原子替换和读回生成，目录写锁与 SQLite 更新序列化。数据库提交后文件失败会明确提示，不报成功；重新打开按最新数据库恢复 Markdown，手工编辑文件不能反向覆盖内核。选择角色标识只是本机所有者为实验指定隔离作用域，不是多人身份认证。角色文件可在“角色记忆文件”查看位置、读取及主动导出。敏感本地记忆不自动发送模型或支持派生。失效不等于删除，不因换话题或新会话清理有效记忆。用户主动删除会擦除可控角色文件和内核投影中的原值，既有外部导出或提供商副本不在删除承诺内。

删除清除本实验内可控记忆版本、派生及回放载荷；后续模型请求不再附带删除前的聊天上下文。原始对话、原始用户输入和用户已导出的文件不随记忆删除而擦除。完整移除本机实验需选择“删除实验”。导出由用户选择守则、记忆和/或对话范围，不含模型 Key；导出 JSON 供分析，不支持任意旧快照覆盖恢复。恢复实验应从本机实验列表打开。

## 演示和图谱

内置数据标记 SIMULATED，不是真实 TeleAgent。播放、暂停、跳转、输入与快照联动；图谱支持旋转、缩放、平移、点选、聚焦和全景。模型实验与固定回放、浏览器模拟沙盒各自隔离。真实实验的时间轴展示实际聊天及治理记录；图形不可用时继续使用二维记忆列表。原模拟沙盒仍只驻留运行内存。

桌面端“会话 ZIP”先只读展示真实批次，不映射成固定轮数。可主动将用户消息绑定当前本地角色，在新实验逐批重新治理；原件保持不变，不调用模型，不将历史助手回答写成记忆。每批均经现有 Store、Markdown 原子更新与读回形成快照／差异，标记 `REEXECUTED_LOCAL`，无变化也如实登记。未能本地核验的内容不写入。重放可停止，已完成批次保留；旧批次重试不复活已删内容。此结果不能当作原平台历史记忆或真实模型重跑。

## 开发与 Windows 构建

只有 macOS 时，使用私有仓库的 Windows Actions 完成原生构建，无须 Windows 电脑。流程及源码白名单见 [Windows 构建说明](../docs/windows-delivery.md)。源码与安装器只通过私有构建仓库交付。

先安装 Node.js 22+、Rust MSVC 工具链、Visual Studio C++ Build Tools、Windows SDK；构建治理程序使用原生 x64 Python 3.10–3.14 和 `PyInstaller==6.16.0`（仅构建依赖，评委无须安装）。

```powershell
cd app
npm ci
python -m pip install PyInstaller==6.16.0
npm run kernel:build
npm run kernel:check
npm run build
npm run check
npm run desktop:windows
```

治理源码改变后必须重新执行 kernel:build。`check-kernel.mjs`核对架构、文件和源码 SHA-256，拒绝使用过期内核。Tauri externalBin 打包 `memory-kernel.exe`；NSIS 为当前用户安装并创建开始菜单入口，默认包含轻量 WebView2 引导器：已有运行时可直接安装，缺失时需联网下载运行时；Actions 手动构建可选完整离线安装器。便携版整理器也包含内核及完整性清单；没有原生构建及实机验收不标记为可交付。不要仅复制主 EXE。

开发模式可设置 `MEMORY_LAB_PYTHON` 为 Python 绝对路径，再运行 `npm run dev`。发布模式只加载同目录已打包内核，不查找系统 Python，不允许前端指定可执行文件或任意数据库路径。Python 以 stdio 调用，不开本地端口；Rust 管理超时、取消、错误和凭据。前端、三维关系、离线演示及静态资源统一位于 `app/`。

私有仓库的固定模拟数据只维护 `app/src/public-demo.json`；桌面 `data.js` 在构建时生成，并与固定演示评估登记逐字节核对，不维护第二份数据源码。历史评估保留原内核哈希，当前内核源码另按 `source-manifest.json` 核验；哈希匹配只证明构建来源，不代表旧评估验证了新实现。

桌面仅交付 Windows 11 x64；`npm run desktop` 也固定使用 Windows 构建入口。macOS 开发机使用共享前端、Python 和原子检查，不生成其他桌面平台的安装包；开发期的主机进程与凭据适配只服务于本地调试，不代表新增交付平台。不再维护独立网页版、Pages 部署或第二套前端依赖；运行 `npm --prefix app run check` 和 `npm --prefix app run build`。Windows 的安装、卸载、升级、凭据库及无开发环境首次启动仍需 Windows 验收；人工视觉、文件面板和 GPU 体验单独确认。第三方许可证见 THIRD_PARTY_NOTICES.txt 及 Cargo.lock 中组件的许可。

对话默认持久化。需要临时处理个人信息时，主动勾选“仅本轮临时处理”：只向模型发送本轮输入和守则，不附带历史或私人记忆，不提取候选或保存对话；临时显示在下一请求、退出或两分钟后清空。提供商副本和既有外部导出不受本应用控制。识别器覆盖明确字段与常见格式，不是完备的语义隐私分类器；含糊内容请主动使用临时模式或先脱敏。历史不安全实验保留原文件但拒绝打开和导出，不自动清洗或迁移。

三维图谱与时间线使用同一轮的实际状态。关系筛选支持更正、派生、冲突及角色归属；选中节点后可查看内容、登记来源、版本关系和对应轮次。二维记忆列表也是键盘访问入口；WebGL 不可用时仍能查看记忆与详情。
