# AI Memory Lab · Windows 11 x64

1. 使用通过校验的 NSIS 安装器安装，从开始菜单打开。便携版完整解压后启动 `AI Memory Lab.exe`，确保同目录有 `memory-kernel.exe`；需要 Microsoft WebView2 Runtime。未签名版本可能出现 SmartScreen 提示，不要关闭系统防护。
2. 左侧“真实模型实验”中配置供应商协议、API 前缀、模型 ID 和 Key，保存后测试连接（会请求所选服务，可能计费）。Key 可临时使用，也可选择系统凭据库存储。编辑已有配置时，Key 留空会保留原凭据；填写新 Key 才会更换。
3. 导入 UTF-8 Markdown 或粘贴守则，填写实验名并新建。旧实验保存自己的守则和哈希，不会自动换用新文本。
4. 发送消息，查看实际回复、候选与处理前后记忆。普通候选可隔离保存；本人确认后仍由 Python 内核裁决。模型说“已记住”不等于落库成功。
5. 配置完成并新建后，设置自动收起；需要时展开“模型与实验守则”。等待期间单独显示未保存的流式回复；保存失败会保留输入和临时预览，重读失败时明确提示核对状态，避免把模型回复当作已提交结果。时间轴查看每轮，记忆演化看具体变化，三维图谱看已登记关系；点击记忆查看来源、版本和派生。WebGL 不可用时使用二维列表。
6. 实验自动保存本机。下次从下拉框打开；中断请求用恢复按钮结束。重命名不改变数据；“重置为新实验”保留原实验；“删除实验”移除本机记录。
7. 导出前选择范围；对话可能含私人内容。导出不含 Key，不是可覆盖导入的备份。删除记忆不会删除原始聊天或已经导出的文件；后续请求停止使用删除前的聊天上下文。

内置 28 轮演示和“本地实验”仍为 SIMULATED，后者为临时浏览器模拟；真实模型实验标为 MODEL_EXPERIMENT，不冒充 TeleAgent。模型调用需要网络；内置演示、历史实验和本地治理可离线使用。

卸载通过 Windows 设置 → 应用；用户实验和系统凭据可能保留。要清除数据，先在应用中删除实验和模型配置。不要手动删除共享 WebView2 或无关目录。

Windows 原生构建、首次启动、断网演示、原生文件面板、凭据保存、卸载重装及无开发环境运行仍需针对最终文件 SHA-256 实机验收。安装器尚未通过这些检查时不作为正式交付包。
