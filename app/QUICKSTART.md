# AI Memory Lab · Windows 11 x64

1. 使用通过校验的 NSIS 安装器安装，从开始菜单打开。便携版完整解压后启动 `AI Memory Lab.exe`，确保同目录有 `memory-kernel.exe`；需要 Microsoft WebView2 Runtime。默认安装包在缺少运行时时联网安装；已有运行时可离线安装和运行。完全离线的首次安装请使用手动构建的离线安装包。未签名版本可能出现 SmartScreen 提示，不要关闭系统防护。
2. 启动后在“开始实验”中配置供应商协议、API 前缀、模型 ID 和 Key，保存后测试连接（会请求所选服务，可能计费）。Key 可临时使用，也可选择系统凭据库存储。编辑已有配置时，Key 留空会保留原凭据；填写新 Key 才会更换。
3. 默认使用应用内置的完整记忆守则，无需下载。也可导入 UTF-8 Markdown 或粘贴文本，预览名称、全文及 SHA-256 后确认。填写实验名并创建；旧实验保存原守则、哈希和已登记来源，不随新选择变化。可随时查看实验守则或恢复内置默认。
4. 发送消息，查看实际回复、候选与处理前后记忆。普通候选可隔离保存；本人确认后仍由 Python 内核裁决。模型说“已记住”不等于落库成功。
5. “对话”看回复并处理候选，“记忆演化”比较具体变化，“三维图谱”查看真实关系；“开始实验”集中管理模型和新实验守则，切换不丢失轮次或选择。等待期间单独显示未保存的流式回复；保存失败会保留输入和临时预览，重读失败时明确提示核对状态，避免把模型回复当作已提交结果。时间轴切换轮次；点击记忆查看来源、版本和派生。WebGL 不可用时使用二维列表。
6. 实验自动保存本机。下次从“实验记录”打开；中断请求用恢复按钮结束。重命名不改变数据；“重置为新实验”保留原实验；“删除实验”移除本机记录。
7. 导出前选择范围；对话可能含私人内容。导出不含 Key，不是可覆盖导入的备份。删除记忆不会删除原始聊天或已经导出的文件；后续请求停止使用删除前的聊天上下文。

首次帮助只有四步，可跳过并从“使用帮助”重开；不会自动发送消息。“离线示例”无需模型配置或 API 额度。

内置 28 轮演示和“本地实验”仍为 SIMULATED，后者为临时浏览器模拟；真实模型实验标为 MODEL_EXPERIMENT，不冒充 TeleAgent。模型调用需要网络；内置演示、历史实验和本地治理可离线使用。

## 逐轮演示与回答核验

“28 轮脚本”可导入官方原始对话流脚本.md，应用核对哈希和连续轮次；文件不随私有应用源码分发，背景卡不能用于输入。选择轮次后主动放入输入框，再自行发送，不会自动调用模型。个人信息和禁存内容不会为复刻脚本而放行，请先最小化或通过本地授权处理。内置示例不代表已执行导入脚本，脚本人物标签不认证身份或授予权限。

在“回答验证”中查看本轮实际发送的记忆、排除原因和聊天上下文。可“填入证据回顾问题”，先选择“不附带记忆和聊天”进行对照，再选择获准记忆发送相同问题。只有已保存的实际回答才可比较；模型、时间和随机性也会影响结果，应用不预设效果改善。上述按钮均不自动发送，也不代表记忆已经提交。

卸载通过 Windows 设置 → 应用；用户实验和系统凭据可能保留。要清除数据，先在应用中删除实验和模型配置。不要手动删除共享 WebView2 或无关目录。

Windows 原生构建、首次启动、断网演示、原生文件面板、凭据保存、卸载重装及无开发环境运行仍需针对最终文件 SHA-256 实机验收。安装器尚未通过这些检查时不作为正式交付包。
