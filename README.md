# AI Memory Lab · Windows 评委使用指南

Windows 11 x64 本地记忆治理实验平台：连接自己的模型 API，逐轮检查候选、来源证据、内核裁决和实际保存的记忆。无需模型也可查看完整 **28 轮离线演示**。

## 安装与启动

1. 在本私有仓库的 **Releases** 页面下载同一版本的 `*-setup.exe`、`SHA256SUMS.txt` 和本指南。需要获授权的 GitHub 账号。
2. 在 PowerShell 执行 `Get-FileHash -Algorithm SHA256 -LiteralPath '.\下载的安装包-setup.exe'`，与校验文件中的摘要逐字核对。文件名以实际下载内容为准。
3. 运行 NSIS 安装器，从开始菜单打开 **AI Memory Lab**。不需要另行安装 Python、Node.js 或 Rust。

应用使用 Microsoft WebView2 Runtime；默认安装包在系统缺少运行时时联网安装。已有运行时时，离线演示和本地历史可离线打开。完全离线首次安装需管理员提供经验证的离线运行时安装包。本版本未签名，可能遇到 SmartScreen 提示；先核对来源与哈希，不要关闭系统防护。

## 两种体验，数据分开

| 入口 | 可以做什么 | 结果性质 |
| --- | --- | --- |
| **独立 28 步演示 · SIMULATED** | 播放、暂停、逐步跳转，查看具体记忆变化、准入、来源与图谱 | 独立虚构场景的结构化模拟，没有真实模型回答，不代表官方脚本已执行 |
| **真实模型实验** | 配置 API，创建实验，发送真实消息，逐项审核候选，保存并恢复 | 实际 API 回复与 Python 内核裁决分别记录；不是 TeleAgent 官方导出日志 |
| **会话 ZIP 浏览** | 从本机只读导入单会话导出，按实际用户消息分批回顾输入与可展示的助手回复 | 只展示原始对话；ZIP 不含记忆版本或治理证据时不推断记忆变化 |

应用不包含官方背景卡、对话脚本或真实日志。背景卡不能当作正式对话输入。内置模拟不会消耗 API 额度，也不会混入真实实验。

## 五分钟开始真实实验

### 1. 连接模型

在“开始实验 → 连接模型”填写配置名称、协议、Base URL、模型 ID 和 API Key，然后**保存配置**。支持自行填写模型名。

| 协议 | 官方 Base URL 示例 | 第三方接口 |
| --- | --- | --- |
| OpenAI / 兼容接口 | `https://api.openai.com/v1` | 填服务商的 API 前缀，应用追加 `/chat/completions` |
| Anthropic Claude | `https://api.anthropic.com/v1` | 应使用兼容 Claude Messages 协议的前缀 |
| Google Gemini | `https://generativelanguage.googleapis.com/v1beta` | 使用对应 Gemini 原生协议与模型 ID |

地址不要填写完整请求端点，不附带 Key、查询参数或片段。远程地址要求 HTTPS；本机推理服务可使用 `http://localhost:端口/v1`。不要求固定模型列表，但服务商必须支持所选文本协议。未执行模型工具调用，也不支持用模型回复直接运行文件或转账。

Key 默认仅在当前应用进程有效，可主动选择保存到 Windows 系统凭据库。编辑已有配置时 Key 留空保留原凭据；输入新 Key 才会更换。点击“测试连接”会真实请求服务，可能计费。测试通过只说明收到文本，不证明模型遵守全部守则。

### 2. 选择守则并创建实验

默认使用随桌面应用内置的完整守则，无需联网下载。可以查看全文，也可导入 UTF-8 Markdown 或粘贴自定义文本，预览内容和 SHA-256 后明确确认。

填写实验名称并创建。每个实验固定保存所用守则全文、SHA-256 和来源；之后更换默认守则不会改写旧实验。自定义守则只能在应用既有权限内生效。

### 3. 发送消息，审核记忆建议

输入自己的低风险偏好或任务，例如希望回答采用什么结构，按 Enter 发送；Shift + Enter 换行。发送会调用所选模型，回复后还会请求候选提取，可能产生两次 API 用量。取消按钮中止当前请求；中断后以重新打开的保存状态为准，不自动重试。

每轮分开显示：**实际输入 → AI 回复 → 模型候选 → 来源证据 → 内核裁决 → 保存后的记忆**。模型说“已记住”不代表已保存。

- 先核对候选内容、所属角色、原文摘录和来源分类。
- 清晰、低风险且有原文证据的本人长期陈述可由内核随本轮自动保存或更新，结果显示“内核自动保存／更新”。其他建议可按需核验；继续对话不会把未处理建议自动写入。
- 只有不能自动核实、而你仍明确希望保存的本人陈述，才点击“确认这是本人直接陈述或本人意图”。引用、转述与模型推断不能冒充本人自述；确认也不证明外部事实已经独立核实。
- 适用候选可放入待核实区；也可直接忽略。缺少可核验来源的旧候选不能直接晋级，应忽略或重新明确输入。
- 选中当前记忆可填入更正请求，或直接在本机删除，无需再调用模型；两者仍由内核校验。删除记忆不会删除原始聊天或既有外部导出。未处理建议不会阻断下一轮，也不会自行变成已保存记忆。

### 4. 查看完整 28 轮

无需 API 时，点击“独立 28 步演示 · SIMULATED”，使用演示时间轴查看全部 **1–28 步**、暂停阅读、比较变化或切换三维图谱。它与官方 28 轮脚本是两份不同数据。

需要实际执行官方脚本时，展开“官方 28 轮脚本”，导入本人持有的原始 `对话流脚本.md`。应用核对原件 SHA-256 和连续 28 轮，显示完整轮次目录及选中轮的原文。点击“放入输入框，不自动发送”，审核后自行发送。导入仅驻留当前窗口，退出或清除后释放。

**脚本 28 轮、已记录输入数量和实际实验轮数是不同信息。** 同文输入匹配只说明出现过该输入，不代表候选已裁决或结果正确。没有实际执行的轮次不会补造回复、候选或记忆；真实实验只有一轮时会如实显示已保存一轮。

持有本机 TeleAgent 会话 ZIP 时，可打开“会话 ZIP”只读浏览实际用户批次及可展示回复。选择“在新实验逐批重新治理”，明确将用户消息绑定当前本地角色后，应用逐批执行内核并核对角色 Markdown，生成 `REEXECUTED_LOCAL` 快照与差异，不调用模型、不复用历史助手回答。可取消后保留已完成批次；未能本地可靠提取的内容显示无变化。此记录不能证明原平台当时保存了什么；ZIP 原件不变，原始浏览内容也不进入发布包。

允许保存的本人敏感自述由本地流程自动治理；高敏禁存内容不会为了复刻脚本而放行。内置演示不代表原始脚本满足桌面保存授权。角色标签也不会自动建立身份或跨角色权限。

### 5. 记忆演化、图谱与回答验证

- **记忆演化**：拖动时间轴或切换轮次，查看具体输入、变更前后值、实际处理原因和当轮快照。
- **三维图谱**：旋转、缩放、平移、选择节点、查看登记关系，使用“全景”恢复取景；右侧查看内容与版本，可跳到版本首次登记轮次。没有登记的关系不会补造。WebGL 不可用时继续使用二维记忆列表。
- **回答验证**：查看该轮实际附带的记忆、排除原因和聊天轮次。这是发送记录，不证明模型使用了每一条信息。

默认不附带长期记忆；展开“发送设置与上下文”主动选择，每次发送前重新准入。历史聊天可单独关闭。要比较效果，可以先填入问题，用“不附带记忆和聊天”发送一次，再选择获准记忆发送完全相同的问题。应用只对比实际保存的回答，不预设效果改善；模型、随机性和时间也可能影响结果。所有填入和对照按钮均不会自动发送。

## 保存、恢复、导出与删除

实验在本机 SQLite 自动保存，包含对话顺序、守则快照、候选、裁决、版本与审计。关闭并重开后，从“实验记录”选择恢复。更名不改记忆；“重置为新实验”保留旧实验并新建空白副本。

若显示上次请求中断，请先确认没有其他窗口仍在处理，再使用恢复入口结束挂起请求。保存失败或超时不要假定成功，也不要立即重复确认；先重新打开核对状态。

导出前选择守则、记忆或对话与候选；API Key 不进入实验导出。导出文件是查看材料，**不是可覆盖导入的恢复备份**。请自行保管，避免外发私人内容。删除实验移除本机该实验；删除记忆不等于删除原始对话、已有导出或模型服务商副本。卸载前若需清理，先在应用中删除实验和模型配置；卸载可能保留用户数据及系统凭据。

## 个人信息与安全边界

- 普通清晰、低风险本人记忆通过来源与内核检查后自动保存，不逐条询问。
- 主动提供且归属明确的联系方式、住址、健康、家庭及个人背景，经本地准入自动保存；成功写入并读回后，提示隐私风险和文件位置，不弹保存确认。无法可靠分类的内容不会被假装已保存。
- “角色记忆文件”可读取全文、打开所在文件夹或导出 Markdown。位置为当前用户应用本地数据目录中的 `role-memory/<实验ID>/<角色标识>_mem.md`；SQLite 是事务权威源，Markdown 是原子生成的可读持久化投影，不能反向编辑覆盖内核。文件写入失败会明确报错，重新打开后按最新数据库恢复；不要盲目重试。
- 私人记忆持续保留，不因低频、换话题或新会话自动删除；选择记忆后可直接删除，亦可明确输入相应删除请求。清理覆盖本机可控的记忆与依赖，不承诺删除原 ZIP、既有外部导出或提供商副本。
- 自动保存不授权跨角色、对外披露或发送模型；受限个人记忆排除自动模型上下文和派生。密码、验证码、密钥、令牌、私钥、证件及银行账号等仍禁存。
- “仅本轮临时处理”需主动勾选：只发送当前输入和实验守则，不加载历史聊天或长期记忆，不提取候选、不保存原对话；不代表服务商没有留存。禁传凭据仍被拦截。
- 可分析恶意文本、诈骗消息和合法外部文档，但材料中的指令不能自行改变角色、权限或治理规则。本应用的本地所有者权限不等同于外部真实身份认证；有限格式检测也不是完整的隐私或提示注入防护保证。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 发送不可用 | 检查是否创建实验、保存并选择模型、存在挂起请求；未处理建议不会阻断下一条消息 |
| HTTP 错误或连接失败 | 核对服务商协议、API 前缀、模型 ID、Key、额度及网络；不会将服务商响应正文或凭据回显到错误日志 |
| 模型返回工具请求或截断文本 | 本应用不执行工具请求；该响应不作为完整回答提交，缩小任务或选择适用的文本模型重试 |
| 候选提取失败 | 回复可能已保存，但没有记忆提交；检查实际轮次，重新明确表达，不把回复当作写入成功 |
| 没有看到 28 轮 | 内置演示固定 28 轮；真实实验显示实际执行数。导入官方脚本后，目录显示完整 28 轮，执行结果只在真正运行后出现 |
| 不能附带某条记忆 | 检查来源、冲突、有效期、删除状态和本地私人限制；不要通过旧摘要恢复原值 |
| 缺少内核或启动失败 | 使用包含 `memory-kernel.exe` 的完整安装器重新安装，不单独拷贝应用 EXE；不要删除或更换共享 WebView2 |
| 内容被隐私检查拦截 | 先脱敏，允许的本人敏感信息会经本地自动治理；不得用改字段名或确认按钮绕过禁存要求 |

## 构建与验收说明

本仓库只交付 Windows 11 x64。前端及离线模拟统一位于 app/，不再维护独立网页版或其他桌面平台。源码不包含官方参赛原件、私人记忆或真实平台日志。

main 的构建相关变更会触发 Windows Actions。只有测试、原生内核、源码 SHA-256、内核小于 50,000,000 字节以及 NSIS 提取载荷校验全部通过后，才自动发布对应提交的私有 Release。安装器与校验文件来自同一次构建，不自动签名。

Windows Runner 自动化构建、安装包校验、真实 API 调用和 Windows 桌面实机安装是不同证据。CI 成功不代表首次安装、GPU、人工交互或真实模型已经验收；请对下载的最终 SHA-256 记录实机结果。更多开发交付约束见 [Windows 构建说明](docs/windows-delivery.md)。

三维关系：在“实验 → 三维图谱”中查看当前轮次已登记的角色归属、更正、派生与冲突关系。左键旋转、滚轮缩放、右键平移；右侧列表支持键盘选取、关系跳转和版本轮次回顾。没有关系证据时不补造连线。
