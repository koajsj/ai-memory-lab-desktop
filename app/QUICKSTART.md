# AI Memory Lab · Windows 11 x64

完整评委操作指南见 [项目 README](../README.md)。Release 附件 `README-Windows.md` 是同一份指南。

安装并核对 SHA-256 → 配置模型与 Key → 选择内置守则并创建实验 → 发送消息 → 核对来源并审核候选 → 记忆演化与图谱 → 回答验证 → 从实验记录恢复或主动导出。

无需 API 时选择“独立 28 步演示 · SIMULATED”。实际官方脚本需本人导入原件并逐轮发送；未执行轮次不生成虚构结果。模型响应、内核裁决和保存结果分别查看。

允许保存的本人私人信息经本地治理自动写入、读回核验后提示隐私风险；高敏凭据仍禁存。不要将 API Key、真实对话或角色记忆提交到仓库。Windows 实机安装和真实模型验收应针对最终安装器 SHA-256 单独记录。
